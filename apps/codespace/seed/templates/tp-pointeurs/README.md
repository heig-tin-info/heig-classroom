# TP 3 — pointeurs et tableaux

`make` compile `hello`. La touche F5 lance gdb par l'extension `webfreak.debug`
(l'image ne fournit pas de configuration de lancement : celle-ci vient du dépôt
modèle de l'enseignant, cf. docs/jalon-0.md § « Consignes pour V1 »).

Le dépôt distant `origin` est le dépôt de transit du portail. `git push` suffit
à rendre : le portail horodate le rendu puis le relaie vers la forge.
