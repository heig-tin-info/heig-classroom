# Liste de classe

## Ce qu'est cette liste

La liste de classe. Chaque ligne est un siège : **pending** tant que l'étudiant ne s'est pas connecté avec l'e-mail correspondant, **claimed** une fois rattaché à son compte. Un badge *staff* marque un siège enseignant (voir plus bas).

## Comment marche le rattachement

Les étudiants rattachent leur siège automatiquement à la première connexion — pas de code d'invitation. En cas de conflit (même étudiant, deux sièges), la ligne est signalée pour que vous tranchiez.

## Gérer les lignes

Le menu en bout de ligne édite la ligne, révoque un rattachement ou retire l'étudiant. Cliquez un e-mail pour écrire à l'étudiant. Changer un e-mail révoque le rattachement de la ligne. **Add students** ouvre le panneau d'import (fichier, un étudiant, ou CSV collé).

## Rejoindre votre propre classe

**Me joindre comme étudiant** vous donne un siège *staff*, exclu de l'effectif : combiné à **Passer en vue étudiant** dans le menu du compte, vous parcourez tout le flux étudiant (accepter, pousser, notes) sans second compte.
