# Notifications

## Toasts dans l'application

Des toasts temps réel apparaissent en bas à droite quand il se passe quelque chose qui vous concerne. Activez chaque type ici — ce réglage est stocké **dans ce navigateur**.

- **Étudiants** : seulement vos propres dépôts et ceux de votre groupe — acceptation, push, note, fichiers protégés restaurés.
- **Équipe enseignante** : les classes dont vous faites actuellement partie, jamais les classes archivées — échéances appliquées, synchronisations et revues LLM de chacune de ces classes, plus l'activité des étudiants (un étudiant rejoint, accepte, pousse, reçoit une note) des classes où **M'avertir de l'activité des étudiants** est activé.

## Par classe

L'interrupteur **M'avertir de l'activité des étudiants** se trouve dans l'onglet Settings de chaque classe et est stocké **sur votre compte**. Il est activé par défaut pour le propriétaire de la classe et désactivé pour les co-enseignants et les assistants. Désactivé, les pages restent à jour en direct ; seuls les toasts s'arrêtent.

## Notifications par e-mail

La section suivante configure les e-mails (nouveau devoir, rappel d'échéance, note finale, échecs de provisioning…). Ces préférences sont stockées **sur votre compte** et vous suivent d'un appareil à l'autre ; chaque message contient aussi un lien de désinscription en un clic pour son type.
