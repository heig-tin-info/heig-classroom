# Mes classes

## Qu'est-ce qu'une classe

Une classe lie une **organisation GitHub** à une **liste d'étudiants**. Les devoirs créés dedans sont distribués sous forme de dépôts privés dans cette organisation, un par étudiant.

## Changer de vue

Le sélecteur de vue au-dessus de la liste bascule entre **cartes**, **liste triable** et **frise chronologique**. Le champ de recherche filtre à la frappe (nom et organisation, correspondance floue).

## Ouvrir les choses

- Cliquez une carte pour ouvrir la classe.
- Cliquez le nom de l'organisation pour l'ouvrir sur GitHub.
- Survolez le nombre d'étudiants pour voir qui est inscrit et qui a déjà rattaché son compte.
- La barre latérale liste vos classes : un clic pour en ouvrir une depuis n'importe quelle page.

## Voir les classes archivées

Cliquez le bouton **archives** à côté du sélecteur de vue. Les classes archivées apparaissent en cartes atténuées avec leur date d'archivage ; **Restaurer** en ramène une parmi les classes actives. Archiver ne supprime rien — données et dépôts GitHub sont conservés.

## Tester l'expérience étudiante

Ouvrez une classe, allez dans l'onglet **Students** et utilisez **Me joindre comme étudiant** : vous prenez un siège *staff* (exclu de l'effectif). Choisissez ensuite **Passer en vue étudiant** dans le menu du compte (bas de la barre latérale) pour voir la vraie vue étudiant — acceptez le devoir, poussez, suivez votre note.
